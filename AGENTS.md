# Working on linked-archi-kernel

Read [`.agents/conventions.md`](.agents/conventions.md) first. It covers what the kernel is, the installed-package consumer contract, and the checklist for finishing a change.

| Path | Holds |
|---|---|
| `.agents/conventions.md` | principles, conventions, workflow, the checklist for finishing a change |
| `.agents/specs/kernel/` | requirements, design, plan, tasks and change log |
| `.agents/tasks/<name>/` | a piece of work someone else may continue |

Kiro reads the same files through `.kiro/`. Claude Code reads `CLAUDE.md`, which imports `.agents/conventions.md`.
